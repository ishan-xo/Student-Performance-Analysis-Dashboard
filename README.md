## 🎯 Project Overview & Objectives
- Identify top-performing and underperforming student cohorts.
- Analyze grade distribution across subjects and demographics.
- Deliver actionable insights for academic intervention.

---

## 🛠️ Data Pipeline & Tools Used
- **Power BI Desktop:** Data modeling, DAX measures, interactive report design.
- **Power Query:** Data cleaning, handling missing values, transforming `student_marks.csv` into `student_marks_upgraded.csv`.
- **Dataset:** Student academic marks dataset (`data/student_marks_upgraded.csv`).
